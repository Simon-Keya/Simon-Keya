# Project screenshot replacement guide

Add genuine project screenshots to this folder, then set the matching `image` property in the project record in `app/page.tsx`. Use crisp desktop screenshots (preferably 16:9 or 3:2) and do not stretch them.

Suggested filenames:
- `restflow.webp`
- `restflow-ai.webp`
- `restflow-go.webp`
- `accommodation-guru.webp`
- `meku-solutions.webp`
- `inarikicchin.webp`

Already connected screenshots in `public/`: `/smans.png` and `/International.png`.

Example: `image: '/projects/restflow.webp'`. Until a real screenshot is added and connected, the existing designed preview remains visible; no fake image files are created.
